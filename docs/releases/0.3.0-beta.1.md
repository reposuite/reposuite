## What was verified

- Pinned checkouts, source-freeze contract diffs, SSH host-key pinning,
  read-only deploy keys, no credentials in archives.
- `verify.sh` artifact gate on the downloaded artifacts (10 checks):
  exact member whitelist, SHA256SUMS exactness, manifest/PINS
  consistency, ELF64-x86_64 executables without setuid, no install
  hooks, frozen launcher byte-identity.
- Gateway `go test ./...` + `-race ./internal/cloud`; Relay full suite +
  full `-race`; Rust release build; 29 release-script guards; lifecycle
  12 assertions; smoke 14 checks; clean-HOME install of both tarballs.
- Two independent `npm pack` repacks of the same payloads are
  byte-identical — archive determinism only; NOT a claim of full
  source→binary reproducibility (hosted runner image/toolchain patch
  levels can vary). `SOURCE_DATE_EPOCH` removes manifest/PINS clock
  variance; `BUILD_ENVIRONMENT.txt` is diagnostic and not inside the
  tarballs.

## Reproduce the artifacts (verification rebuild — NOT approval)

Docs HEAD is not the build pin; rebuilt bytes are not automatically
approved for publication. On Ubuntu 22.04 with Go 1.27.1, Rust 1.93.1,
Node 24, npm 11.21.1, and the two deploy keys:

```bash
git clone git@github.com:reposuite/reposuite.git reposuite && cd reposuite
git checkout 93b1f1b29f0e72fbaf15ee39a45677645ba84f53
git clone git@github.com:rceman/reposuite-gateway.git ../reposuite-gateway
git -C ../reposuite-gateway checkout deec606ea7ed6623c666e6116fcc5b8db4257fca
git clone git@github.com:rceman/reposuite-relay.git ../reposuite-relay
git -C ../reposuite-relay checkout 0aa45414668ca03a7abd8f1a1a0d80ae35ce8137
export GATEWAY_SHA=deec606ea7ed6623c666e6116fcc5b8db4257fca
export RELAY_SHA=0aa45414668ca03a7abd8f1a1a0d80ae35ce8137
bash scripts/release/prepare.sh 0.3.0-beta.1
bash scripts/release/build.sh
bash scripts/release/package.sh
bash scripts/release/verify.sh
```
