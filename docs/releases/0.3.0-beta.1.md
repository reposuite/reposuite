## Toolchains / compatibility

Go 1.27.1 (both services, verified via `go version` on the binaries);
rustc/cargo 1.93.1; gcc 11.4.0; Ubuntu 22.04 host (glibc 2.35);
node v24.22.1; npm 11.21.1. Runtime floor: both dynamic binaries need
at most GLIBC_2.34, Relay is static, Gateway requires `libsqlite3.so.0`.
